# WorkflowAPI Specification Skill

Use this skill when changing the core DSL, document model, bridges, nested workflows, schemas, examples, or compatibility rules. Update prose, JSON Schema, examples, validator tests, and ADRs for major changes.

Before finishing:

- Check affected docs.
- Check affected schemas.
- Check examples and tests.
- State compatibility and security impact.
- Do not broaden scope beyond the requested slice.
